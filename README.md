# HospitalCare - Arquitetura de Software

Projeto desenvolvido para a disciplina de Arquitetura de Software.

O HospitalCare é um sistema de gerenciamento hospitalar criado para organizar informações de pacientes, médicos e consultas, aplicando conceitos de arquitetura de software.

## Conceitos utilizados

- Modelo C4 para documentação da arquitetura
- Arquitetura em camadas
- Padrão MVC
- Estrutura cliente-servidor

## Objetivo

Aplicar os conceitos aprendidos em aula na modelagem e organização de um sistema de software.
